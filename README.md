## Aim

## Problem Statement

To design a user-friendly wireframe for a Medicine Reminder Application using Balsamiq, ensuring easy medication management, timely reminders, and an intuitive user experience.

## Algorithm
## Design
1. Splash / Welcome Screen
2. Login / Registration Screen
3. Home Dashboard Screen
4. Medicine Schedule & Reminder Screen
5. Add Medicine / Confirmation Screen

## Output

## Medicine Reminder Application using Balsamiq

The wireframe was designed to help users manage their daily medications efficiently. The application flow begins with a welcome screen, followed by user authentication. After login, users can view their medication schedules, add medicines, receive reminders, and track medication history through a simple and organized interface.
